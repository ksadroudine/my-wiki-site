## Summary

This glossary defines the terms that appear most often in the AI part of the Book of Knowledge. Each entry gives a short plain-language definition and points to the Concept where the term is explained in depth. Terms are listed in alphabetical order, and where a term is used differently by different sources, the definition follows the Concept that covers it.

## Glossary of AI Terms

| Term | Meaning | See |
|------|---------|-----|
| A2A (Agent2Agent) | An open protocol that lets AI agents from different vendors coordinate directly with one another. | [Agentic AI Platform Architecture](#/concept/agentic-ai-platform-architecture) |
| Agent (AI agent) | Software that pursues a goal on its own by perceiving its environment, planning, acting through tools and adjusting from feedback, instead of only answering a prompt. | [Agentic AI Fundamentals](#/concept/agentic-ai-fundamentals) |
| Agentic AI | AI systems built from agents that make decisions and carry out multi-step work with limited human direction. | [Agentic AI Fundamentals](#/concept/agentic-ai-fundamentals) |
| AI factory | A decision engine made of a data pipeline, algorithm development, an experimentation platform and supporting software, which lets a company run and improve its operations with AI. | [AI Factory](#/concept/ai-factory) |
| Algorithmic audit | A systematic review of an algorithmic system that identifies how it could harm the people it affects and sets up monitoring for those harms. | [Algorithmic Auditing and AI Failures](#/concept/algorithmic-auditing-and-ai-failures) |
| Artificial general intelligence (AGI) | A theorized AI whose abilities match a human's across the full range of thinking tasks, as opposed to narrow AI built for one task. | [Artificial General Intelligence](#/concept/artificial-general-intelligence) |
| Attention | The mechanism in the Transformer that lets a model weigh every part of a passage when interpreting any one word. | [AI and Machine Learning Foundations](#/concept/ai-and-machine-learning-foundations) |
| Context window | The amount of text a model can take into account at one time when it answers. | [LLM Mechanics, Limitations and Scaling](#/concept/llm-mechanics-limitations-and-scaling) |
| Deep learning | A branch of machine learning that uses neural networks with many layers, and works well on images, text and audio. | [AI and Machine Learning Foundations](#/concept/ai-and-machine-learning-foundations) |
| Evals | Automated tests that show whether an AI model or application is safe and good enough to release, and whether it keeps working afterward. | [2025 AI Industry Vocabulary](#/concept/ai-industry-vocabulary-2025) |
| Federated learning | A way for several organizations to train a shared model on their combined data without any of them handing over raw data. | [Federated Machine Learning](#/concept/federated-machine-learning) |
| Fine-tuning | A short extra round of training that adapts a general model to a narrower task using a smaller set of examples. | [AI and Machine Learning Foundations](#/concept/ai-and-machine-learning-foundations) |
| Foundation model | A model trained on broad data that can be adapted to many tasks, and the starting point for most current generative AI. | [AI and Machine Learning Foundations](#/concept/ai-and-machine-learning-foundations) |
| Guardrails | Checks placed around an AI system that filter risky inputs and correct or block inaccurate or inappropriate output. | [AI Risk Controls and Output Reliability](#/concept/ai-risk-controls-and-reliability) |
| Hallucination | A confident statement by a language model that is made up or wrong. | [LLM Mechanics, Limitations and Scaling](#/concept/llm-mechanics-limitations-and-scaling) |
| Jagged frontier | The uneven boundary of what AI can do, which does not follow human intuitions about which tasks are easy or hard. | [Working Effectively with Generative AI](#/concept/working-with-generative-ai) |
| Knowledge distillation | Training a smaller, cheaper model to imitate the outputs of a larger one. | [DeepSeek and China's AI Ecosystem](#/concept/deepseek-and-chinas-ai-ecosystem) |
| Large language model (LLM) | A foundation model trained on text that can generate and analyze language, and the technology behind most chatbots. | [AI and Machine Learning Foundations](#/concept/ai-and-machine-learning-foundations) |
| Machine learning | A way of building software in which the system learns its own rules from examples instead of following rules written by a programmer. | [AI and Machine Learning Foundations](#/concept/ai-and-machine-learning-foundations) |
| MCP (Model Context Protocol) | An open standard that gives AI agents secure access to external tools and data while they work. | [Agentic AI Platform Architecture](#/concept/agentic-ai-platform-architecture) |
| Mixture of experts | A model design that spreads the work across specialized sub-models and limits data movement between them, which lowers cost. | [DeepSeek and China's AI Ecosystem](#/concept/deepseek-and-chinas-ai-ecosystem) |
| Narrow AI | AI built for one specific, well-defined problem, which describes nearly all AI in use today. | [Artificial General Intelligence](#/concept/artificial-general-intelligence) |
| Neural network | A model made of connected processing units loosely inspired by brain cells, which adjusts its connections as it learns. | [AI and Machine Learning Foundations](#/concept/ai-and-machine-learning-foundations) |
| Orchestrator agent | An agent that breaks a goal into subtasks, assigns them to other agents and tracks progress. | [Agentic AI Platform Architecture](#/concept/agentic-ai-platform-architecture) |
| Overfitting | A fault in which a model fits its training data so closely that it performs worse on new data. | [Data Mining Fundamentals](#/concept/data-mining-fundamentals) |
| Parameter | A number inside a model that is adjusted during training, so that more parameters generally allow more detailed knowledge. | [LLM Mechanics, Limitations and Scaling](#/concept/llm-mechanics-limitations-and-scaling) |
| Prediction (economic sense) | Using the data you have to fill in information you lack, which covers forecasting as well as classifying uncertain facts. | [Prediction Machines](#/concept/prediction-machines) |
| Prompt | The input text given to a language model, including instructions, context and examples. | [Working Effectively with Generative AI](#/concept/working-with-generative-ai) |
| Reasoning model | A model that works through a problem in several steps, backtracking and revising, at a higher computing cost. | [2025 AI Industry Vocabulary](#/concept/ai-industry-vocabulary-2025) |
| Recursive self-improvement | A loop in which one AI model builds a more capable successor, which in turn builds a better one. | [Artificial General Intelligence](#/concept/artificial-general-intelligence) |
| Red teaming | Deliberately attacking an AI system to find weaknesses before real users or attackers do. | [Algorithmic Auditing and AI Failures](#/concept/algorithmic-auditing-and-ai-failures) |
| Retrieval-augmented generation (RAG) | A method in which the system first retrieves relevant passages from an organization's own documents and gives them to the model so that its answer is grounded in them. | [Retrieval-Augmented Generation (RAG)](#/concept/retrieval-augmented-generation) |
| Scaling law | The observed regularity that bigger models, more data and more computing reliably improve next-word prediction. | [LLM Mechanics, Limitations and Scaling](#/concept/llm-mechanics-limitations-and-scaling) |
| Semantic layer | A machine-readable layer of shared definitions, relationships and rules that lets AI agents interpret enterprise data consistently. | [Semantic Layer for Agentic AI](#/concept/semantic-layer-for-agentic-ai) |
| Shadow AI | Use of AI tools by employees without their organization's approval or knowledge. | [AI-Driven Work and Organizational Redesign](#/concept/ai-work-and-organization-redesign) |
| Sovereign AI | AI capability built under the control of a nation or organization rather than depending on foreign providers. | [Sovereign AI Ecosystems](#/concept/sovereign-ai-ecosystems) |
| Synthetic data | Training data produced by one AI model for another to learn from. | [2025 AI Industry Vocabulary](#/concept/ai-industry-vocabulary-2025) |
| Token | The small piece of text, often part of a word, that a language model reads and produces one at a time. | [LLM Mechanics, Limitations and Scaling](#/concept/llm-mechanics-limitations-and-scaling) |
| Transformer | The neural network design, introduced in 2017, that processes an entire passage at once using attention, and underlies most large language models. | [AI and Machine Learning Foundations](#/concept/ai-and-machine-learning-foundations) |
| Vibe coding | Building working software by describing it to an AI in natural language instead of writing the code by hand. | [Vibe Coding and AI-Led Development](#/concept/vibe-coding-and-ai-led-development) |
| Vibes (vibe check) | Judging a chatbot by the qualitative feel of its answers rather than by benchmark scores. | [2025 AI Industry Vocabulary](#/concept/ai-industry-vocabulary-2025) |
| Workslop | AI-generated content that looks polished but lacks the substance to move a task forward. | [Organizational Readiness for AI Collaboration](#/concept/organizational-readiness-for-ai-collaboration) |
